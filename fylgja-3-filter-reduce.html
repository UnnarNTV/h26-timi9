Fylgið mér 3: filter, find & reduce

Kóðinn fer í js/fylgja-3-filter-reduce.js. Hafið console opna (F12 / Cmd + Option + I).

ÆFING 1

filter: dýrar vörur

const verd = [1290, 450, 3990, 790, 2490];

Haltu bara verðum yfir 1000 kr.

ÆFING 2

filter: nöfn sem byrja á staf

const nofn = ["Sigga", "Jón", "Sara", "Anna", "Stefán", "Óli"];

Vísbending: "Sigga".startsWith("S") er true

ÆFING 3

find: leita að vöru

Vörur: Mjólk, Brauð, Ostur, Epli, Kaffi, Súkkulaði

ÆFING 4

reduce: summa

Leggðu saman öll verðin í verd. Skoðaðu console: hver umferð er skrifuð þar.

ÆFING 5

reduce: telja stafi

Hversu margir stafir eru í öllum nöfnunum samtals?

ÆFING 6

Keðja: filter → map → reduce

Samtals verð allra vara sem kosta minna en 1000 kr. Sýnum hvert skref.

ÆFING 7

Spáðu fyrir: hvað skilar þetta?

Skrifaðu niður svarið fyrst. Smelltu svo til að sjá hvort þú hafðir rétt.

a)  [1, 2, 3].map((x) => x + 1)
b)  [1, 2, 3].filter((x) => x > 5)
c)  [1, 2, 3].find((x) => x > 5)
d)  [1, 2, 3].reduce((s, x) => s + x, 10)
e)  [1, 2, 3].forEach((x) => x * 2)
